# Evorxa Cloud for WHMCS

Resell Evorxa VPS and VDS servers from WHMCS with automatic provisioning, a full client control panel and the Evorxa Manager admin addon.

Documentation (shipped inside the module):

- [Overview & screenshots](modules/servers/evorxa/docs/README.md)
- [Installation guide](modules/servers/evorxa/docs/INSTALL.md)
- [How to use](modules/servers/evorxa/docs/USAGE.md)
- [Changelog](modules/servers/evorxa/docs/CHANGELOG.md)

Development: `bin/deploy.sh /path/to/whmcs [owner:group]` copies the module into a WHMCS install; `bin/package.sh` builds the upload-ready zip in `dist/` (same contents as Evorxa Manager > Install / Export).
